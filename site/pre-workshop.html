需要準備的帳號與軟體

三個步驟，請依序完成。

1

付費的 Claude 帳號

Claude Code 需要 Pro、Max、Team 或 Enterprise 方案，免費帳號無法使用，沒有例外。

訂閱費用補助

上課當天出示訂閱證明（收據或訂閱確認畫面），現場補助新台幣 500 元訂閱費用。

前往訂閱 Pro 方案 ↗

若課後不繼續使用，可依方案規定取消訂閱。若你的帳號是公司或學校配發、且無法升級，請在課前回信告知，會安排課堂上兩人一組共用一個帳號。

確認方式 完成第 2 步安裝後，打開 Claude 桌面版，點最上方的 Code 分頁。 能輸入文字即可使用；若跳出升級提示，代表方案還不能用，請回到上方連結訂閱。
2

安裝 Claude 桌面版

全程使用桌面版，不會使用終端機。

Mac 下載 ↗ Windows 下載 ↗

安裝完成後打開，用第 1 步的帳號登入。Windows 使用者請額外安裝 Git for Windows，安裝時使用預設選項即可；Mac 通常已內建，不需另外安裝。

3

GitHub 帳號

用來存放與發布你做出來的工具，免費方案就夠用。

註冊 GitHub ↗

註冊後請收信完成信箱驗證——未驗證的帳號無法建立儲存庫。若沒收到驗證信，請檢查垃圾郵件匣。請記住你的帳號名稱，上課時會用到。

為什麼第 1 步不能跳過

Claude Code 是這堂課使用的工具，只有付費方案能用。這是課前準備裡唯一沒有替代方案的一項，其餘兩步裝不起來都還有其他辦法，這一步沒有。
