# 三小時流程表（免費版，講師用）

**這份檔案是這個版本的時間與順序的唯一真實來源。** 改動任何一段長度時，先改這裡，
再去同步 `slides/deck.md`、`workbook/`、`site/index.html`。

## ⚠️ 這個版本比付費版多花時間，而且這是誠實的代價

**總長 195 分鐘（3 小時 15 分），不是 180 分鐘。**

原因很直接：付費版讓 Claude Code 自己動手存檔、打開瀏覽器；這個版本每一步
「把文字變成檔案」都要學員親手做，而且**非程式背景的學員這一步做得比你想的慢**。
把時間壓縮到 180 分鐘，代價通常是 Lab 3 做不完、或跳過手機打開那個高潮。

**場地就是只有 180 分鐘的話**，按這個順序砍：

| 順序 | 砍什麼 | 省多少 |
| --- | --- | --- |
| 1 | Lab 3 的首頁步驟（步驟 2），直接開 Pages 指到 `/habits/` | 約 7 分 |
| 2 | 觀念段落砍到 8 分鐘，只留 claude.ai 和 GitHub 兩個詞 | 約 4 分 |
| 3 | 收束論證的「誠實的那一半」壓成兩件事而不是三件 | 約 3 分 |

**不要砍 Lab 0 的存檔練習，也不要砍洞見段落**——理由跟付費版一樣：
這堂課的論證是「先體驗，再命名」，砍掉體驗，後面的洞見就沒有東西可以指。

## 🧠 洞見段落：讀 `insights.md`，不要只看投影片

跟付費版一樣，四段 🧠 標記的內容**投影片上只有結論，理由在
[`insights.md`](insights.md)**。這個版本的洞見論證跟付費版**不一樣**——不是
「翻譯變便宜了」，而是「翻譯今天沒有變便宜，但你因此看清楚它本來的樣子」。
上台前務必讀熟，尤其這個反過來的論證第一次講會不順口。

## 0:00–0:12 開場 + 現場 Demo

**跟付費版最大的不同：demo 要示範完整的「問、貼、存、開」四步驟，不能只做「問」。**

在 claude.ai 貼上生日倒數的提示詞，等它回答，**現場真的複製、貼到記事本、
存檔、雙擊打開**。全程讓學員看到滑鼠怎麼動——這是他們今天要重複十幾次的動作，
現在先看一次完整流程比什麼都有用。

**看什麼：** 這一段的目的不是「AI 很厲害」，是「這套流程我學得會」。
Demo 結束收在「我剛剛做了三件事：問、貼、存」，直接點名今天的核心動作。

**落後時：** 不能砍，這是整場的鉤子，而且是唯一能提前示範存檔技巧的機會。

---

## 0:12–0:24 觀念：三個名詞

三個詞：claude.ai（免費聊天，不是 Claude Code）、Repo、GitHub。

**一定要講的一件事：** 「Code 分頁不要點，那個要付費。」現場帶大家看一眼畫面確認。

**看什麼：** 問「有人用過 GitHub 嗎？」決定 Lab 0 要講多細。

**落後時：** 砍到 8 分鐘，claude.ai 和 GitHub 兩個詞留著，Repo 在 Lab 0 邊做邊講。

---

## 0:24–0:49 Lab 0：帳號 + 練習存檔

→ `workbook/lab-0-setup.md`

**這是這個版本最容易崩的 25 分鐘**，而且崩的方式跟付費版不一樣——付費版卡在
「帳號要不要付費」，這個版本卡在「存檔類型選錯」「忘記製作純文字」這類
機械性的小地方。

**節奏：**

- 0:24–0:27 開 claude.ai 帳號（3 分）
- 0:27–0:32 開 GitHub 帳號 + 建 repo，**確認 Public**（5 分）
- 0:32–0:45 **全班一起做一次存檔練習**：貼 `<h1>Hello</h1>`，存成
  `test.html`，雙擊打開（13 分——這是今天最重要的技能，給足時間）
- 0:45–0:49 檢查點，走動排除個別問題（4 分）

**看什麼：** 走動看螢幕。Windows 使用者先確認「顯示副檔名」有沒有打開——
沒開這個，學員自己完全看不出檔案是不是存錯了。

**落後時：** Repo 的 README 可以不管，但**存檔練習不能省**——
Lab 1 開始學員就要獨立做這件事，Lab 0 沒學會，Lab 1 會整個卡住。

---

## 0:49–1:29 Lab 1：記帳小工具

→ `workbook/lab-1-expenses.md`

第一次真的自己動手做完整流程。重點不是記帳，是**把 Lab 0 學的技能真的用一次，
而且用到「不滿意就整份換掉」的程度**。

**節奏：**

- 0:49–0:53 講「怎麼跟它講話」，特別強調「請給我完整程式碼」這句（4 分）
- 0:53–1:05 貼第一個提示詞，做出 v1，存檔打開（12 分）
- 1:05–1:20 **改一個東西**：複製新版本、全選蓋掉、存檔、重新整理（15 分——
  這是洞見 1 的燃料，給最多時間）
- 1:20–1:29 存回 GitHub（9 分）

> ⚠️ 「改一個東西」那一步是洞見 1 的燃料，跟付費版一樣的道理。
> 差別是這個版本的「改」要多做四個機械動作（複製、全選、貼上、存檔），
> 學員第一次做可能會慢，不要催。

**看什麼：** 有人會不知道「全選蓋掉」是什麼意思，直接用手動刪除想改的那幾行。
走過去示範一次 `Ctrl+A` 全選再貼上，比用講的快。

**落後時：** 砍掉存回 GitHub 那步，留到 Lab 2 開頭補。本機能動最重要。

---

## 1:29–1:32 🧠 洞見 1：一件事會被自動化，一件事不會

→ 講稿：[`insights.md`](insights.md#洞見-1) · 投影片 33–36

**開場問全場：「剛剛複製貼上幾次？改了幾次版本？」** 等他們回答再翻頁。

核心：今天做的事分兩種——複製貼上存檔是機械性的，決定要什麼、判斷對不對是
判斷性的。付費工具拿走的是機械性那一半，判斷性那一半**永遠是你的**。

**看什麼：** 這段講完直接進休息，不用停下來解釋。

**落後時：** 只講「兩種事」和最後那句，一分鐘講完，不要整段砍掉。

---

## 1:32–1:42 休息

**休息前把鉤子講掉：**

> 「剛剛那個東西要你自己雙擊才會動。等一下我們要做一個你在睡覺時它自己會動的東西——
> 而且完全不用碰電腦裡的軟體。」

走動處理落後的人，這 10 分鐘是唯一的緩衝。

## 1:42–2:12 Lab 2：每天自動幫你做事

→ `workbook/lab-2-digest.md`

**這一段幾乎跟付費版一樣**，因為 GitHub Actions 純粹是網頁操作，
跟學員今天有沒有用 Claude Code 完全無關——這正是洞見 2 要講的事。

**節奏：**

- 1:42–1:47 講 GitHub Actions 是什麼（5 分）
- 1:47–1:57 貼提示詞跟 Claude 要兩個檔案（10 分）
- 1:57–2:05 把兩個檔案貼到 GitHub（8 分——**兩次** Add file 流程，比付費版多一步）
- 2:05–2:12 手動觸發跑一次，看成果（7 分）

**技術上最容易爆的點：**

1. 路徑打錯——`.github/workflows/digest.yml` 少了開頭的點，或打成
   `github/workflow/`，GitHub Actions 就完全抓不到這個檔案。
2. 兩個檔案順序搞混，貼錯位置。

參考解：`../../instructor/reference/digest-workflow.yml` 和
`fetch-digest.mjs`——**跟付費版共用同一份**，不用另外準備。

**看什麼：** 紅色 ✗ 一樣是好教材，把錯誤訊息貼回聊天視窗修好。

**落後時：** 砍掉「改成自己想要的來源」，用預設的 RSS 就好。

## 2:12–2:15 🧠 洞見 2：付費工具在省的是哪一段

→ 講稿：[`insights.md`](insights.md#洞見-2) · 投影片 47–50

核心：GitHub Actions 不在乎檔案是複製貼上還是自動寫進去的——對它來說是同一件事。
所以付費工具的價值不是「讓自動化變得可能」（本來就可能），是幫你省掉
複製、貼上、存檔那前幾步。

**落後時：** 只講「對 GitHub 來說是同一件事」那張，30 秒。

---

## 2:15–2:50 Lab 3：習慣儀表板 + 上線

→ `workbook/lab-3-habits.md`

**結尾一樣要給一個真的網址。**

**節奏：**

- 2:15–2:25 習慣追蹤表，本機測試（10 分）
- 2:25–2:32 首頁，本機測試（7 分）
- 2:32–2:40 三個檔案存回 GitHub（8 分）
- 2:40–2:50 開 Pages、等待、手機打開（10 分）

**技術上最容易爆的兩個點：**

1. repo 必須是 Public（Lab 0 應該處理掉了，這裡再確認一次）。
2. Pages 第一次部署要等 1–10 分鐘，**這個版本連後續更新也可能要等一下**，
   跟付費版不同（付費版本機打開是即時的）。先講，否則學員會以為自己做錯了。

**看什麼：** 手機打開那一步不要省，這是今天的情緒高點。

**落後時：** 砍掉首頁步驟，直接開 Pages，網址指到 `/habits/`
（見上方 180 分鐘版建議的第一刀）。

---

## 2:50–2:53 🧠 洞見 3：你比很多人多讀過一遍程式碼

→ 講稿：[`insights.md`](insights.md#洞見-3) · 投影片 63–66

核心：因為今天每一段程式碼都要親手複製貼上，學員其實被迫逐字看過每一份檔案，
這是用自動化工具的人不一定會做的事。收在同一條判準：越難收回的事，
越要親眼看過再放行。

**落後時：** 只講「看起來對 ≠ 對」和那條判準，30 秒。

---

## 2:53–2:58 成果分享

找 2–3 個人念出自己的網址，全場一起打開。控制在 5 分鐘。

---

## 2:58–3:10 🧠 收束論證：今天真正發生的事

→ 講稿：[`insights.md`](insights.md#收束論證) · 投影片 68–80

跟付費版用同一個「三件事」框架（知道要什麼／翻譯／確認對不對），
**但結論相反**：付費版說「翻譯變便宜了」，這個版本說「翻譯今天沒有變便宜，
但你因此看清楚它本來的樣子」。這個反轉是這份教材最容易講錯的地方，
上台前務必把 `insights.md` 讀熟。

**「誠實的那一半」三件事不能省**，最後一件（「今天的方便是有代價的」）
是這個版本特有的，直接呼應學員剛剛做的複製貼上——如果不講，
結尾會顯得像在硬拗一個限制成優點。

**落後時：** 「誠實的那一半」壓成兩件事（砍第三件），四段壓成 8 分鐘。

---

## 3:10–3:15 收尾

投影片 81–87，快速帶過：三個坑、五句救命的話、三個回家作業、兩組帶走的重點。

最後一句要留給「回家如果想換更快的工具」這個橋接——不要講成推銷，
是很自然地回答「今天複製貼上讓你覺得麻煩」這個大概率會有的感受。

      沒有的話開場先帶全班打開

每個 Lab 開始時：

- [ ] 把該 Lab 的提示詞投影出來，**整段唸一次**

每個 Lab 結束時：

- [ ] 問「做出來的舉手」，數一下。低於 2/3 就多給 5 分鐘，從分享段借
      （不要從洞見段落借）
