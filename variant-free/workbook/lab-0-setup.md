# Lab 0：把工具準備好（25 分鐘）

## 這一段結束時，你會有

- 一個 claude.ai 帳號（**免費**）
- 一個 GitHub repo，而且是 **Public**
- **學會把 AI 給你的文字變成一個真的檔案**——這是今天最關鍵的技能

> 今天完全不用安裝任何軟體、不用付任何錢。代價是有幾個步驟要**手動做**，
> 這份手冊會一步一步帶你過。撐過這 20 分鐘，後面就是不斷重複同一招。

---

## 步驟 1：開一個 claude.ai 帳號

打開 https://claude.ai ，用 Email 或 Google 帳號註冊。**免費方案就夠了，不用訂閱。**

> ⚠️ **登入後畫面上方可能會看到一個 Code 分頁——今天請不要點它。**
> 那是需要付費的功能。我們今天只用**一般的聊天視窗**（畫面中間可以打字的那個框），
> 跟你平常跟 AI 聊天一樣。

**你應該會看到**：一個可以打字問問題的聊天畫面。

---

## 步驟 2：開一個 GitHub 帳號

打開 https://github.com/signup 註冊，免費方案就夠了。

註冊完請**收信點開驗證信**完成驗證——沒驗證的帳號沒辦法建立儲存庫，
而且驗證信有時候會躺在垃圾郵件匣。

**把你的帳號名稱記起來**，等一下要用。

---

## 步驟 3：建立你的 repo

打開 https://github.com/new，填三個地方：

| 欄位 | 填什麼 |
| --- | --- |
| Repository name | `my-life-tools` |
| Public / Private | **Public** ⚠️ |
| Add a README file | **打勾** ✅ |

按最下面的 **Create repository**。

> ⚠️ **一定要選 Public。** 今天最後要把作品變成公開網址，
> 免費帳號的 Private repo 做不到。

**你應該會看到**：一個網址是 `https://github.com/你的帳號/my-life-tools` 的頁面，
裡面有一個 `README.md`。

---

## 步驟 4：學會「把文字變成檔案」⭐ 今天最重要的技能

Claude 給你的東西**永遠只是文字**——它不會自己變成一個能打開的網頁。
今天每一個 Lab，你都會重複同一個動作四步驟：

```
複製 Claude 給的文字  →  貼到純文字編輯器  →  存成正確的檔名  →  雙擊打開
```

**現在就練一次，之後就不用再解釋了。**

### Windows：用「記事本」

1. 點左下角開始選單，打字搜尋「**記事本**」，打開它
2. 複製貼上這段測試文字：

```html
<h1>Hello, 我做出來了！</h1>
```

3. 上方選單 **檔案 → 另存新檔**
4. **「存檔類型」選「所有檔案 (\*.\*)」**——這一步最容易漏掉，不選這個等一下會存錯
5. 「檔案名稱」直接打 `test.html`（要包含 `.html`）
6. 存到桌面，按存檔
7. 到桌面找到那個檔案，**滑鼠雙擊**

**你應該會看到**：瀏覽器打開，畫面上一行大字「Hello, 我做出來了！」

> ⚠️ **如果雙擊後開的是記事本，不是瀏覽器**——代表你的檔案其實叫
> `test.html.txt`。回到第 4 步，「存檔類型」一定要選「所有檔案」，不能留在
> 「文字文件 (\*.txt)」。

### Mac：用「文字編輯」

1. 按 `Cmd + Space` 打開 Spotlight，打字搜尋「**文字編輯**」，打開它（TextEdit）
2. **先做這一步，不然等一下會存壞**：上方選單 **格式 → 製作純文字**
   （快速鍵 `Shift + Cmd + T`）
3. 複製貼上這段測試文字：

```html
<h1>Hello, 我做出來了！</h1>
```

4. 上方選單 **檔案 → 儲存**
5. 檔案名稱打 `test.html`（要包含 `.html`）
6. 存到桌面，按儲存
7. 到桌面找到那個檔案，**滑鼠雙擊**

**你應該會看到**：瀏覽器打開，畫面上一行大字「Hello, 我做出來了！」

> ⚠️ **如果打開是一堆看不懂的符號、格式跑掉**——代表你漏了第 2 步「製作純文字」。
> 文字編輯預設會存成有格式的文件（RTF），那種格式電腦看不懂 HTML。
> 重新開一個新檔案，記得先按 `Shift + Cmd + T`，再貼文字。

## 落後了？

如果測試檔案怎麼存都不對，換個角度：**先確認你的電腦有沒有「顯示副檔名」**。

- **Windows**：檔案總管 → 上方「檢視」→ 打勾「副檔名」，這樣你才看得到
  自己存的檔案到底叫 `test.html` 還是 `test.html.txt`
- **Mac**：文字編輯的存檔視窗裡，通常有一個「若沒有副檔名則使用 .txt」的選項，
  **確認它沒有被勾選**

還是卡住的話，直接舉手找講師，這個問題現場排除比看文字說明快。
