# 帶回家的小抄（免費版）

印出來或存書籤。這一頁是三小時裡真正需要記住的東西。

---

## 一、講話的公式

大部分「它給的不是我要的」，原因都是**話講太短**。補上這四件事就會準很多：

> **我要做什麼** + **有哪些功能** + **我要看到什麼** + **有什麼限制**

而且**免費版一定要多加一句**：

> **「請給我完整、可以直接存成檔案使用的程式碼，不要省略任何部分。」**

❌ `做一個待辦清單`

✅ ```
做一個待辦清單網頁，單一個 index.html：
可以新增、打勾完成、刪除，資料存在瀏覽器裡。
中文介面，手機上能用。
請給我完整、可以直接存成檔案使用的程式碼，不要省略。
```

---

## 二、四步驟：把文字變成檔案

這是今天重複最多次的動作：

```
複製 Claude 給的文字  →  貼到記事本／文字編輯  →  存成正確檔名  →  雙擊打開
```

**改東西的時候：**

```
複製新的完整版本  →  全選舊內容蓋掉  →  存檔  →  重新整理瀏覽器
```

**Mac 使用者永遠記得先做這步**：貼上之前，先按 `Shift + Cmd + T`（製作純文字），
不然存出來的檔案會壞掉。

## 三、五句救命的話

```text
（貼上錯誤訊息）請告訴我哪裡有問題，並給我修好之後的完整程式碼
```

```text
請重新給我完整版本，不要省略任何一行、不要用「...」帶過
```

```text
我用雙擊打開這個檔案，畫面是空白的，主控台（F12）出現這個錯誤：（貼上）
```

```text
這個放到 GitHub Pages 上連結點不到，我用的路徑是（貼上），請給我修好的完整版本
```

```text
用我聽得懂的方式解釋你剛剛做了什麼，不要用專有名詞
```

> **最重要的一句是第一句。** 看到紅色的字或畫面不對，不要慌、不要自己讀——
> **整段複製，貼回去，說「請修好，給我完整版本」。**

## 四、腦袋裡帶走的三句話

> ### 一件事會被自動化，一件事不會
>
> 今天你複製、貼上、存檔這幾個動作，是可以被工具自動做掉的部分——
> 這正是 Claude Code 這類工具在做的事。但**決定要做什麼、判斷做出來的對不對**，
> 這兩件事永遠是你的。今天你把兩件事都做了一遍，之後就算工具幫你代勞了前面那件，
> 你也知道自己在確認什麼。

> ### 看起來對 ≠ 對
>
> 危險的不是它給你的東西看起來很爛——那個你一眼就看得出來。
> 危險的是它給你**看起來很對、但其實不對**的東西。
> 今天因為你要親手複製貼上每一段程式碼，你其實比很多用自動化工具的人
> **看過更多它實際寫了什麼**——這是免費版意外的優點，別浪費它。

> ### 越難收回的事，越要親眼看過再放行
>
> 存在自己電腦裡的測試檔案？隨便試。貼到 GitHub、按下 Commit？
> 先看一眼內容對不對再按。

## 五、GitHub 名詞對照

| 你看到的 | 白話 |
| --- | --- |
| repository / repo | 一個會記得所有版本的資料夾 |
| Add file → Create new file | 在 GitHub 網頁上新增一個檔案 |
| Commit changes | 存檔，並留下「我這次改了什麼」的紀錄 |
| Actions | GitHub 借你的雲端電腦，可以按時間自動做事 |
| workflow | 給那台電腦的紙條：幾點做、做什麼 |
| Pages | 把你的網頁變成一個公開網址 |

## 六、回家繼續的三個題目

由易到難，做完一個再做下一個：

1. **改你今天做的東西。** 把記帳工具改成你真的會用的樣子。
2. **改每日摘要。** 換成你真正想每天收到的：你追的網站、天氣、匯率。
3. **做一個只有你需要的東西。** 想一件你每週都要手動做一次的瑣事，
   描述給 Claude，讓它幫你想解法。

**如果今天的「複製貼上」流程讓你覺得麻煩**——那正是 Claude Code 這類工具存在的理由。
它做的事，跟你今天做的事一模一樣，只是幫你把複製、貼上、存檔那幾步自動化掉了。
今天你知道那幾步實際在做什麼，之後要不要換更快的工具，是你自己的選擇。
