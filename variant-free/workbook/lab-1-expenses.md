# Lab 1：記帳小工具（40 分鐘）

## 這一段結束時，你會有

- 一個可以在電腦上開啟的記帳網頁
- 一次「查看結果 → 補充需求 → 更新完整檔案」的經驗
- 你的作品出現在 GitHub 上

> 記帳是練習題目。這一段要練習的是**清楚描述需求**，
> 以及**把 AI 回覆建立成可以操作的檔案**。

---

## 先講一件事：怎麼跟它講話

比較以下兩個例子的資訊完整度：

❌ **條件不足**

```text
做一個記帳的東西
```

✅ **講清楚「有什麼功能」和「我要看到什麼」，而且要求完整檔案**

```text
做一個記帳網頁，可以輸入金額和項目、能刪掉、最上面顯示總花費，
資料要存得住，畫面乾淨、手機能用，單一個 index.html 檔案就好，不要用任何套件。
請直接給我完整、可以存成檔案直接打開使用的程式碼，不要省略任何部分、不要用「...」帶過。
```

> **最後一句「請給我完整程式碼」很重要。** AI 回覆有時會省略部分內容。
> 這個版本需要把回答直接存成完整檔案，因此每次都要明確提出要求。

---

## 步驟 1：跟 Claude 要第一版

在 claude.ai 的聊天視窗貼上這段話：

```text
做一個記帳小工具，單一個 index.html 檔案就好，不要用任何套件。
功能：
1. 可以輸入金額、項目名稱，按一下就新增一筆
2. 下面列出所有紀錄，每一筆可以刪掉
3. 最上面顯示這個月的總花費
4. 資料存在瀏覽器裡，關掉再打開還在
畫面請做得乾淨好看，中文介面，手機上也要能用。
請直接給我完整、可以存成 index.html 直接打開使用的程式碼，不要省略任何部分。
```

它會回覆一段程式碼。你不需要逐行閱讀，後續會直接驗證畫面與功能。

---

## 步驟 2：建立網頁檔案

使用 Lab 0 的操作方式：

1. 找到 Claude 回答裡程式碼區塊右上角的**複製**按鈕（或框選整段按 `Ctrl+C` / `Cmd+C`）
2. 打開記事本（Windows）或文字編輯（Mac，**記得先按 `Shift+Cmd+T` 製作純文字**）
3. 貼上（`Ctrl+V` / `Cmd+V`）
4. 存成 `expenses.html`（Windows 記得「存檔類型」選「所有檔案」）
5. 雙擊打開

**你應該會看到**：一個記帳頁面。**實際輸入幾筆試試看**，然後**重新整理瀏覽器**——
資料應該還在。

> 如果畫面空白或格式不正確，先查看本頁的「遇到問題？」表格。

---

## 步驟 3：改成你想要的樣子 ⭐

**這一步比第一版更重要。**

第一版可能仍需調整，例如顏色、字級或功能。請先選一項修改。

回到同一個聊天視窗（**不要開新的對話**，這樣它才記得你原本的程式碼），
貼上你想加的東西：

```text
幫我加上「分類」功能：新增的時候可以選餐飲、交通、購物、其他，
列表上用不同顏色的標籤顯示，最上面再加一個各分類的小計。
請一樣給我完整、可以直接存成檔案使用的程式碼，不要只給片段。
```

它會回一個**新的、完整的**檔案。這次不用重打字，直接：

1. 整段複製新的程式碼
2. 回到記事本／文字編輯，**全選舊內容**（`Ctrl+A` / `Cmd+A`）
3. 貼上新的蓋掉舊的
4. 存檔（`Ctrl+S` / `Cmd+S` 就好，不用重新選檔名）
5. 回到瀏覽器，**重新整理**

> **需要調整時，直接補充需求，不用重新開始。**
> 因為它每次都給你「整份完整檔案」，你只要「全選蓋掉、存檔、重新整理」，
> 不用自行修改程式碼。請親手完成一次更新與驗證。

一些可以直接用的點子：

- 「幫我加一個圖表，看這個月每個分類花了多少」
- 「顏色改成暖色系，我想要看起來溫暖一點」
- 「金額加上千分位逗號，並顯示新台幣符號」

## 步驟 4：存回 GitHub

確認功能後，把它放進你的 repo：

1. 打開你的 repo：`https://github.com/你的帳號/my-life-tools`
2. 按綠色的 **Add file → Create new file**
3. 在「Name your file」欄位打 `expenses/index.html`
   （**打斜線 GitHub 會自動幫你建 `expenses` 資料夾**，不用另外新增）
4. 把你電腦裡那個檔案的內容整段複製，貼進下面的編輯框
5. 往下捲，按綠色的 **Commit changes**

**你應該會看到**：repo 首頁多了一個 `expenses/` 資料夾，點進去看得到 `index.html`。

## 遇到問題？

| 你看到的 | 怎麼辦 |
| --- | --- |
| 雙擊打不開、開成別的程式 | 回 Lab 0 步驟 4，多半是存檔類型或副檔名的問題 |
| 打開是空白畫面 | 打開瀏覽器的開發者工具（按 `F12`），看 Console 分頁有沒有紅字，把紅字整段複製，回聊天視窗貼上：「這是錯誤訊息：（貼上）請修好，一樣給我完整檔案」 |
| 重新整理資料就不見了 | 部分瀏覽器會限制以 `file://` 開啟頁面的儲存功能。可改用 Chrome 或 Edge；仍無法使用時，查看「延伸練習」的做法 |
| 它回答的程式碼看起來被截斷、中間寫「...」 | 回它：「你剛剛的程式碼被截斷了，請重新給我完整版本，不要省略任何一行」 |
| GitHub 貼上後畫面顯示一堆奇怪符號 | 確認你複製的是**程式碼本身**，不是連著 Claude 的說明文字一起複製 |
