# Lab 3：習慣儀表板 + 讓全世界打得開（35 分鐘）

## 這一段結束時，你會有

- 一個習慣追蹤儀表板
- 一個把三個工具串起來的首頁
- **一個真的網址**，用手機就能打開，可以傳給別人看 ⭐

> 前兩個 Lab 的成果只有你看得到。
> 這一段結束時，你會有一個能傳到家族群組裡的網址。

---

## 步驟 1：做習慣追蹤表（本機測試）

跟 Lab 1 一樣的流程：問 Claude → 複製 → 貼到記事本／文字編輯 → 存檔 → 雙擊。

貼給 Claude：

```text
做一個習慣追蹤表，單一個 index.html：
1. 我可以自己新增想追蹤的習慣（例如喝水、運動、閱讀）
2. 顯示最近 30 天的格子，點一下代表那天有做到，變成綠色
3. 每個習慣顯示「連續達成幾天」
4. 資料存在瀏覽器裡，關掉再打開還在
中文介面，手機上要能用。
請給我完整、可以存成 index.html 直接打開使用的程式碼，不要省略。
```

存成 `habits.html`，雙擊打開，**點幾格試試看，重新整理，顏色應該還在**。

不滿意就繼續改，做法跟 Lab 1 一樣：貼想加的功能 → 複製新版本 →
記事本全選蓋掉 → 存檔 → 重新整理瀏覽器。

---

## 步驟 2：做一個首頁（本機測試）

現在你有三個東西散在不同地方，需要一個門面把它們串起來。

```text
做一個首頁 index.html，用卡片的方式連到我的三個工具：
- expenses/index.html 記帳小工具
- habits/index.html 習慣追蹤表
- digest/ 每日摘要
連結請用相對路徑，例如 href="expenses/index.html"，不要用完整網址。
風格要跟前面的工具一致，中文介面，手機上要好看。
最上面放一個標題「我的生活小工具」。
請給我完整、可以存成 index.html 直接使用的程式碼。
```

> ⚠️ **這裡連結一定要用相對路徑**（像 `expenses/index.html`），
> 不能是本機路徑（像 `C:\Users\...`）。等一下上線之後，
> 只有相對路徑才找得到正確的檔案。

存成 `home.html`，雙擊打開**先看畫面長什麼樣**——連結現在點了會找不到頁面，
這是正常的，因為現在檔案分散在你電腦不同地方，等推上 GitHub 之後結構就對了。

---

## 步驟 3：把三個檔案存回 GitHub

依序做三次「Add file → Create new file」：

| 你電腦上的檔案 | GitHub 上要建的路徑 |
| --- | --- |
| `habits.html` | `habits/index.html` |
| `home.html`（首頁） | `index.html`（**不要加資料夾，直接放根目錄**） |

`expenses/index.html` 應該在 Lab 1 已經放好了，這裡不用重做。

每一次都是：**Add file → Create new file → 打路徑 → 貼內容 → Commit changes**。

**你應該會看到**：repo 首頁除了 `expenses/`、`digest/`，現在多了 `habits/` 資料夾，
而且根目錄直接有一個 `index.html`（不在任何資料夾裡）。

---

## 步驟 4：讓全世界都打得開 ⭐

這一步完全在 GitHub 網頁上做：

1. 你的 repo → 上排 **Settings**
2. **左邊**選單往下捲，找到 **Pages**（在 "Code and automation" 那一區，
   **不是上排的分頁**）
3. **Source** 選 **Deploy from a branch**
4. **Branch** 選 **main**，右邊資料夾選 **/ (root)**
5. 按 **Save**

然後你會拿到網址：`https://你的帳號.github.io/my-life-tools/`

---

## ⚠️ 現在打開可能是 404 — 這是正常的

**第一次部署要等 1–10 分鐘。** 趁等待的時候，把網址傳給自己，或跟旁邊的人聊聊今天做了什麼。

**之後每次你再改東西存回 GitHub，網站也需要一點時間更新**——通常沒有第一次那麼久，
但也可能要等幾分鐘。**改完別急著檢查，先做別的事，等一下再回來看。**

---

這一步不要省。在自己手機上打開自己做的網站，是這三小時最好的部分。

## 打開是 404？按這個順序查

| # | 檢查 | 怎麼修 |
| --- | --- | --- |
| 1 | 才剛按 Save？ | 再等 5 分鐘，第一次部署很慢 |
| 2 | repo 是 Public 嗎？ | Settings → 最下面 Danger Zone → Change visibility → Public |
| 3 | 網址結尾有 `/` 嗎？ | `.../my-life-tools/` |
| 4 | repo 名字大小寫對嗎？ | 要完全一樣 |
| 5 | 根目錄有 `index.html` 嗎？ | 到 repo 首頁確認，**不是**在某個資料夾裡面 |

樣式跑掉、連結點了 404？多半是路徑寫錯，回聊天視窗貼：

```text
這個網站放到 GitHub Pages 上連結點不到，我用的路徑是（貼上你寫的 href）。
請告訴我應該怎麼寫，並給我修好之後的完整 index.html。
```
