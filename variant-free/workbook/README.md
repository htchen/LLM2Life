## 今天重複最多次的動作

```
問 Claude  →  複製它給的文字  →  貼到記事本／文字編輯  →  存成正確檔名  →  雙擊打開
```

改東西的時候：**複製新版本 → 全選舊內容蓋掉 → 存檔 → 重新整理瀏覽器**。

這項操作會在 Lab 0 練習一次，後續三個 Lab 會重複使用。

## 需要追上進度時

每個 Lab 都有「需要追上進度？」區塊，內含可以直接使用的提示詞。

先加入目前進行的段落，前面的內容可於課後補做。

## 三項操作重點

1. **有些步驟可以自動化，有些責任仍由使用者承擔。** 工具可以代為複製貼上，
   需求、決策與結果驗證仍由使用者負責。
2. **看到紅字或畫面不對 → 整段複製 → 貼回去 → 「請修好，給我完整版本」。**
3. **每次都要求「完整程式碼」。** 否則 AI 回覆可能以「...」省略部分內容。
