## 今天重複最多次的動作

```
問 Claude  →  複製它給的文字  →  貼到記事本／文字編輯  →  存成正確檔名  →  雙擊打開
```

改東西的時候：**複製新版本 → 全選舊內容蓋掉 → 存檔 → 重新整理瀏覽器**。

這一招在 Lab 0 學一次，後面三個 Lab 一直重複用。

## 落後了怎麼辦

**每個 Lab 都有「落後了？」區塊**，裡面有一段可以直接貼上、一次做完的提示詞。

不要從頭追。**跳到大家正在做的那一段**，前面的課後再補。

## 三件今天一定要帶走的事

1. **一件事會被自動化，一件事不會。** 複製貼上可以被工具代勞，
   決定要什麼、判斷對不對，永遠是你的。
2. **看到紅字或畫面不對 → 整段複製 → 貼回去 → 「請修好，給我完整版本」。**
3. **每次都要求「完整程式碼」。** 少了這句，AI 有時候會用「...」偷懶帶過。
