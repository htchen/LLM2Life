# 專題 1：蒐集發想並選定題目（15 分鐘）

## 這一段結束時，你會有

- 三個來自生活或工作的題目
- 一個適合在課堂完成的專題方向
- 一句不先假設解法的問題描述

## 步驟 1：先找問題

回想最近兩週，寫下三件重複整理、記錄、比對或判斷的工作。每個題目只寫一行：

> 我在＿＿＿＿情境中，需要＿＿＿＿，目前用＿＿＿＿處理，主要問題是＿＿＿＿。

## 步驟 2：選擇適合課堂的題目

題目需要同時符合：你熟悉、一個核心問題、能用一個畫面展示、風險低。
若需要登入、資料庫、付款、敏感個資、付費 API 或多人同步，先縮小範圍。

## 步驟 3：請 AI 協助比較

```text
我正在選一個工作坊中的個人小工具題目。以下是三個問題：
1. （題目一）
2. （題目二）
3. （題目三）

請依照「我是否熟悉、能否用一個畫面展示、是否能在一小時內做出最小版本、風險是否低」比較。
先整理比較，不要寫程式，也不要替我決定。
```

## ✅ 檢查點

- [ ] 我選定一個題目
- [ ] 我能用一句話說明目前問題
- [ ] 題目不需要登入、付款、敏感個資或多人同步

沒有題目時，可選個人清單、簡單計算器、追蹤表、資料整理頁或決策輔助表。
