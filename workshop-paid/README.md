# 用 AI 和 GitHub 把發想做成可操作工具（Claude Code 付費版）

**課堂預設使用的是[免費版](../workshop/)。** 這一版保留給主辦單位統一付費、
或參與者已具備 Pro 以上方案之場次。兩版使用相同的開放式專題架構，產出亦相同。

主要差別：

| | 免費版（主線） | 本版 |
| --- | --- | --- |
| 工具 | claude.ai 聊天介面 + GitHub 網頁介面 | Claude Code（桌面版為主要路徑） |
| 帳號 | 免費帳號即可 | **需 Pro 以上方案**，免費帳號無法使用 |
| 存檔 | 參與者自行把回覆存成檔案 | 由 Claude Code 直接寫入 |
| 總長 | 195 分鐘 | 180 分鐘 |

**免費帳號無法使用 Claude Code** 是方案限制而非模型限制，也是這一版不作為預設的原因。
統一付費之作法與成本估算見 [`../shared/provisioning-tokens.md`](../shared/provisioning-tokens.md)。
