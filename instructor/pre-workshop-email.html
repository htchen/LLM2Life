第一封

課前 5–7 天寄出

主要通知信 課前 5–7 天
主旨
【課前必做，約 20 分鐘】用 Claude Code 把發想做成可操作工具 — 上課前請完成這三件事
內文
嗨，

這是一堂全程動手做的課。你會從生活或工作中的問題出發，完成發想、規劃與兩輪實作，並展示一個可操作的最小版本。

你不需要任何程式背景。但你需要在上課前準備好環境，否則課堂前段需要先處理安裝，會減少實作時間。

請在上課前完成以下三件事，大約 20 分鐘。


① 準備一個付費的 Claude 帳號 ⚠️

這是唯一沒有替代方案的一項，請務必先確認。

Claude Code 需要 Pro、Max、Team 或 Enterprise 方案。免費的 Claude 帳號無法使用，這一點沒有例外。

到 https://claude.com/pricing 訂閱 Pro 方案；若課後不繼續使用，可依方案規定取消。

訂閱費用補助：上課當天出示訂閱證明（收據或訂閱確認畫面），現場補助新台幣 500 元。

怎麼確認你的方案可以用：完成下面第 ② 步之後，打開 Claude 桌面版，點最上方中間的 Code 分頁。

看到可以輸入文字的畫面 → 你可以用
跳出要你「升級方案」→ 你的帳號還不能用，請回來訂閱

如果你的公司/學校帳號有限制，或不確定，請在上課前回信告訴我，我會幫你安排課堂上兩人一組共用。


② 安裝 Claude 桌面版

我們不會使用終端機，全程使用桌面版。

Mac：https://claude.ai/download
Windows：https://claude.com/download

下載後安裝、打開、用你第 ① 步的帳號登入。

Windows 使用者請額外裝 Git for Windows：https://git-scm.com/downloads/win
（可使用安裝程式的預設選項；Mac 通常已內建，不需另外安裝。）


③ 準備一個 GitHub 帳號

到 https://github.com/signup 註冊，免費方案就夠了。

註冊完請收信點開驗證信完成驗證——沒驗證的帳號沒辦法建立儲存庫，如果沒有收到驗證信，請檢查垃圾郵件匣。

請把你的帳號名稱記起來，上課時會用到。


上課當天請帶

・筆電（不是 iPad 或平板，需要能安裝軟體）
・電源線
・手機（若專題發布成網站，可用手機驗證）


課前 30 秒自我檢查

全部確認就準備好了：

・打開 Claude 桌面版，點 Code 分頁，沒有跳出要我升級
・我能登入 github.com，而且信箱已驗證
・筆電電源線在包包裡了

有任何一項無法完成，請直接回這封信，不要等到上課當天。

課堂見！

第二封

提醒信 課前 1 天
主旨
明天見！最後確認一件事（30 秒）
內文
嗨，明天上課前請花 30 秒確認：

打開 Claude 桌面版 → 點最上方的 Code 分頁 → 有沒有跳出要你升級付費方案？

沒跳出 → 你準備好了，明天見。
跳出來了 → Claude Code 需要付費方案（Pro 以上），免費帳號無法使用。可在 https://claude.com/pricing 訂閱；若未能及時完成，也請照常出席，我會安排你跟其他同學兩人一組。

記得帶筆電、電源線、手機。

明天見！

講師備註

不寄給學員，留在這裡自己看

  • 訂閱費用補助：每位學員最高新台幣 500 元，10 人上限為新台幣 5,000 元。請當天備妥現金，並在報到處確認每位學員的訂閱證明後再給付，避免重複請領。
  • 可預留 10–20% 的學員尚未完成訂閱，事先安排兩人一組的分組方式。
  • 收到「我用公司電腦裝不了軟體」的回覆時，回覆他們用 claude.ai/code（只要瀏覽器，不用安裝），並提醒他們仍然需要付費方案。
  • 課前信不需提到終端機、Node.js 或 npm，因為這堂課不會使用這些工具。
