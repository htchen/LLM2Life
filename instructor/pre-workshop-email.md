# 課前通知信（直接複製寄出）

**寄送時機：課前 5–7 天寄第一封，課前 1 天寄提醒。**

課前準備沒做好，前 20 分鐘會全部拿去裝軟體，三個 Lab 只做得完兩個。
這封信最重要的一句話是「Claude Code 需要付費方案」——免費帳號**完全無法**使用，
而這件事學員不會自己發現。

---

> 💡 **如果主辦方要統一付費**（不要求學員自己訂閱），
> 請先讀 [`provisioning-tokens.md`](provisioning-tokens.md)——用 Console 預付額度加上
> **per-user 花費上限**，30 人三小時大約 US$300–600。那份文件裡有這封信要怎麼改。
> 下面這個版本是「學員自付」的預設版本。

## 第一封（課前 5–7 天）

> **主旨：【課前必做，約 20 分鐘】用 Claude Code 打造生活小工具 — 上課前請完成這三件事**
>
> 嗨，
>
> 這是一堂**全程動手做**的課。三小時內你會做出三個能用的小工具，
> 最後拿到一個全世界都打得開的網址。
>
> 你**不需要**任何程式背景。但你需要在上課前準備好環境，
> 否則前半堂課會拿去裝軟體，很可惜。
>
> 請在上課前完成以下三件事，大約 20 分鐘。
>
> ---
>
> ### ① 準備一個「付費的」Claude 帳號 ⚠️ 最重要
>
> **這是唯一沒有替代方案的一項，請務必先確認。**
>
> Claude Code 需要 **Pro、Max、Team 或 Enterprise** 方案。
> **免費的 Claude 帳號無法使用**，這一點沒有例外。
>
> 到 https://claude.com/pricing 訂閱 Pro 方案（可以先訂一個月，課後不想留可以取消）。
>
> **怎麼確認你的方案可以用：** 完成下面第 ② 步之後，打開 Claude 桌面版，
> 點最上方中間的 **Code** 分頁。
>
> - 看到可以輸入文字的畫面 → ✅ 你可以用
> - 跳出要你「升級方案」→ ❌ 你的帳號還不能用，請回來訂閱
>
> 如果你的公司/學校帳號有限制，或不確定，**請在上課前回信告訴我**，
> 我會幫你安排課堂上兩人一組共用。
>
> ---
>
> ### ② 安裝 Claude 桌面版
>
> 我們**不會用到終端機**（那個黑黑的視窗），全程用有畫面的桌面版。
>
> - **Mac**：https://claude.ai/download
> - **Windows**：https://claude.com/download
>
> 下載後安裝、打開、用你第 ① 步的帳號登入。
>
> Windows 使用者請額外裝 **Git for Windows**：https://git-scm.com/downloads/win
> （一路按「下一步」就好，Mac 通常已內建，不用裝。）
>
> ---
>
> ### ③ 準備一個 GitHub 帳號
>
> 到 https://github.com/signup 註冊，免費方案就夠了。
>
> 註冊完請**收信點開驗證信**完成驗證——沒驗證的帳號沒辦法建立儲存庫，
> 而且驗證信有時候會躺在垃圾郵件匣。
>
> 請把你的帳號名稱記起來，上課時會用到。
>
> ---
>
> ### 上課當天請帶
>
> - 筆電（**不是** iPad 或平板，需要能安裝軟體）
> - 電源線
> - 手機（最後一段會用手機打開你自己做的網站）
>
> ---
>
> ### 課前 30 秒自我檢查
>
> 全部打勾就準備好了：
>
> - [ ] 打開 Claude 桌面版，點 **Code** 分頁，**沒有**跳出要我升級
> - [ ] 我能登入 github.com，而且信箱已驗證
> - [ ] 筆電電源線在包包裡了
>
> 有任何一項卡住，**直接回這封信**，不要等到上課當天。
>
> 課堂見！

---

## 第二封（課前 1 天，簡短提醒）

> **主旨：明天見！最後確認一件事（30 秒）**
>
> 嗨，明天上課前請花 30 秒確認：
>
> **打開 Claude 桌面版 → 點最上方的 Code 分頁 → 有沒有跳出要你升級付費方案？**
>
> - 沒跳出 → 你準備好了，明天見。
> - 跳出來了 → Claude Code 需要付費方案（Pro 以上），免費帳號無法使用。
>   還來得及在 https://claude.com/pricing 訂閱。真的來不及也請直接來，
>   我會安排你跟其他同學兩人一組。
>
> 記得帶**筆電、電源線、手機**。
>
> 明天見！

## 講師備註

- **一定會有人沒訂閱。** 抓 10–20% 的人課前沒處理好，這是正常比例，不是通知信寫得不好。
  兩人一組的方案要事先想好怎麼分，不要當場才想。
- 收到「我用公司電腦裝不了軟體」的回覆時，回覆他們用 `claude.ai/code`（只要瀏覽器，
  不用安裝），並提醒他們仍然需要付費方案。
- 不要在課前信裡提終端機、Node.js、npm。非程式背景的人看到會直接放棄，
  而這堂課完全用不到。
