這三小時在練什麼

課程不以完成固定的範例工具為目標，而是走完一次可以重複使用的專題流程。 題目與功能是開放的，流程與檢查點是固定的。

  1. 1提出問題
  2. 2定義目標
  3. 3拆解計畫
  4. 4分段實作
  5. 5驗證
  6. 6決定下一步

前段用共同題目建立基本操作能力，後段由學員提出自己的真實需求。 每一個步驟都要有可以自己檢查的結果，未完成的功能列入下一版，不列為失敗。 完整的段落與時間分配見 instructor/timeline.md。

開課前必須知道的三件事

這三項是最常在課程前十五分鐘造成落隊的原因。

學員只需要免費帳號

claude.ai 免費方案加上 GitHub 免費方案就夠，不必訂閱，也不必安裝任何軟體。 課前只要確認兩個帳號都能登入、GitHub 信箱已完成驗證。

學員要自己把 AI 回覆存成檔案

這是免費版唯一的機制差異：複製完整程式碼、貼進文字編輯器、存檔、打開。 也因此每個提示詞結尾都要寫「請給我完整程式碼」——AI 用「⋯」省略內容時， 學員會存出一個壞掉的檔案。

學員的 repo 必須是 Public

免費帳號要使用 GitHub Pages，repo 必須公開。建立時就選 Public， 課程中途才改會多花五分鐘。

要開這門課的人，先讀這幾份

  • 60 分鐘演講版投影片 給種子教師場次：不動手，用兩段現場示範說明這套流程值得帶回去。流程表 talk-60.md，逐張講稿 talk-60-script.md。
  • 三小時上課投影片（免費版 · 主線） 在瀏覽器直接翻頁瀏覽，可全螢幕。付費版在 slides-paid.html。
  • 種子教師指南 上完課要自己開一場時從這裡開始：現成的教材、開課前的決定、可以改與不建議改的部分。
  • 流程表（免費版） 時間與順序的唯一真實來源，195 分鐘完整版與 180 分鐘縮短方式。改動任何一段的長度，都先從這裡開始。
  • 免費版講師說明 免費版特有的三件事：判斷與檔案操作的分工、單一檔案原則、每一輪都要保存完整版本。
  • 論證與帶領原則 兩版共用。各階段的教學目的、提問方式、範圍判斷，以及補充段落「AI 演進與人的判斷」的完整推導與追問回應。
  • 課前通知信（免費版） 一定要寄。免費版沒有安裝問題，但仍要確認兩個帳號都能登入。
  • 疑難排解（免費版） 現場最常出現的錯誤與處理順序。
  • 帳號與費用估算 改用付費版時才需要：學員自備方案、Console 額度與免費變體的取捨比較。

把這份帶回去，教其他老師

這份教材是為了「被拿去教」而設計的：除了投影片與學員手冊， 講師需要的流程表、帶領原則、疑難排解與課前通知信都在 repo 裡。 上完課的老師可以直接重跑一次給校內其他老師，不必自己重寫一套。 開課前先讀 種子教師指南。
