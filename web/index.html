這三小時在練什麼

課程不以完成固定的範例工具為目標，而是走完一次可以重複使用的專題流程。 題目與功能是開放的，流程與檢查點是固定的。

  1. 1提出問題
  2. 2定義目標
  3. 3拆解計畫
  4. 4分段實作
  5. 5驗證
  6. 6決定下一步

前段用共同題目建立基本操作能力，後段由學員提出自己的真實需求。 每一個步驟都要有可以自己檢查的結果，未完成的功能列入下一版，不列為失敗。 完整的段落與時間分配見 instructor/timeline.md。

開課前必須知道的三件事

這三項是最常在課程前十五分鐘造成落隊的原因。

Claude Code 需要付費方案

Pro / Max / Team / Enterprise 皆可，免費帳號無法使用。這不是模型的限制，是方案的限制。 沒有付費方案時，改用上面的免費版教材。

主要路線是桌面版，不是終端機

桌面版內建 Claude Code，不需要安裝 Node.js、不必操作指令列，而且看得到視覺化的變更對照。 終端機是選配；安裝失敗時改用瀏覽器版 claude.ai/code。

學員的 repo 必須是 Public

免費帳號要使用 GitHub Pages，repo 必須公開。建立時就選 Public， 課程中途才改會多花五分鐘。

教材結構

同一套內容分布在四個介面：投影片、手冊、隨堂網站、講師文件。原始檔全部在 GitHub 上。

資料夾給誰內容

starter/選配學員 repo 的範本
variant-free/講師免費變體的完整教材，自成一套

要開這門課的人，先讀這幾份

  • 流程表 時間與順序的唯一真實來源。改動任何一段的長度，都先從這裡開始。
  • 講師說明與帶領原則 各階段的教學目的、提問方式、範圍判斷，以及補充段落的完整論證與追問回應。
  • 課前通知信 一定要寄。沒有寄，課程前段就得用來處理安裝與帳號問題。
  • 疑難排解 現場最常出現的錯誤與處理順序。
  • 帳號與費用估算 學員自備方案、Console 額度與免費變體的取捨比較。
