## 三個 Lab 的關係

```
Lab 1   在我的電腦上能跑
   ↓
Lab 2   我不在的時候它自己會跑
   ↓
Lab 3   全世界都打得開
```

三個 Lab 都做在同一個 repo（`my-life-tools`）的不同資料夾裡，
所以 GitHub 只要設定一次。

## 落後了怎麼辦

**每個 Lab 都有「落後了？」區塊**，裡面有一段可以直接貼上、一次做完的提示詞。

不要從頭追。**跳到大家正在做的那一段**，前面的課後再補——
今天的重點是把每一種「做得到」都體驗過一次，不是把每一格都填滿。

## 三件今天一定要帶走的事

1. **不滿意就再講一次，不用重來。**
2. **看到紅色錯誤 → 整段複製 → 貼回去 → 「請修好它」。**
3. **講得囉唆比講得漂亮有用。** 把你知道的限制先講出來。
