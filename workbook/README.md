# 學員手冊

這份手冊帶你從一項真實需求開始，完成發想、規劃、實作與驗證。**不需要程式背景。**

## 今天會重複的流程

```text
提出問題 → 縮小目標 → 定義驗收條件 → 拆解步驟
→ 一次實作一步 → 測試 → 保存版本 → 決定下一步
```

共同練習使用指定題目，個人專題則由你選擇熟悉的生活或工作需求。

## 題目範圍

課堂專題限定為：

- 一個主要使用者
- 一個核心問題
- 一個可以操作與展示的流程
- 不涉及付款、敏感個資、醫療判斷或自動對外寄送

需要登入、多人同步、資料庫或外部付費服務的功能，先列入「下一版」。

## 需要追上進度時

先保留一個能操作的核心流程。尚未完成的功能記錄在「下一版」，不要同時增加多項需求。

## 三項操作重點

1. **先定義完成後應該看到什麼，再開始實作。**
2. **一次只做一個可驗收步驟，測試通過後保存版本。**
3. **實作結果改變了理解時，可以更新計畫。** 計畫用來協助判斷，不是不能修改的規則。
