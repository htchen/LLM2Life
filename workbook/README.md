# 學員手冊

這份手冊帶你在三小時內完成三個工具，並發布成一個公開網站。**不需要程式背景。**

## 今天的路線

| | Lab | 你會做出 | 時間 |
| --- | --- | --- | --- |
| 0 | [把工具準備好](lab-0-setup.md) | 一個 GitHub repo，而且能上傳改動 | 20 分 |
| 1 | [記帳小工具](lab-1-expenses.md) | 一個能用的記帳網頁 | 33 分 |
| 2 | [每天自動幫你做事](lab-2-digest.md) | 每天早上自動產生的新聞摘要 | 34 分 |
| 3 | [習慣儀表板 + 發布成公開網站](lab-3-habits.md) | **一個公開網站** | 33 分 |

📄 [**帶回家的重點整理**](prompt-cheatsheet.md) — 只有這一頁需要留著

## 三個 Lab 的關係

```
Lab 1   在我的電腦上能跑
   ↓
Lab 2   我不在的時候它自己會跑
   ↓
Lab 3   任何人都能開啟
```

三個 Lab 都做在同一個 repo（`my-life-tools`）的不同資料夾裡，
所以 GitHub 只要設定一次。

## 需要追上進度時

**每個 Lab 都有「需要追上進度？」區塊**，裡面提供可以直接使用的提示詞。

請先進行全班目前所在的段落，先前未完成的內容可於課後補做。

## 三項操作重點

1. **結果不符合需求時，補充條件後再修改。**
2. **看到紅色錯誤時，完整複製訊息並貼回 Claude Code。**
3. **需求描述要包含功能、預期結果和限制。**
