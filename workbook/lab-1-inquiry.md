# 共同練習：探究提問卡（25 分鐘）

## 這一段結束時，你會有

- 一個可以使用的「探究提問卡」網頁，關閉後再開啟仍會保留資料
- 一次根據實際結果補充需求並修改的經驗
- 你的作品出現在 GitHub 上

> 探究提問卡是這一段的練習題目。學習重點是**如何把需求說明清楚**。

**這個工具在課堂上怎麼用：** 學生輸入一個自己觀察到的現象，工具把它配上固定的提問句型，
幫助學生從「我看到了什麼」走到「我可以問什麼、可以怎麼檢驗」。
學生只是打開這個網頁使用，**不需要任何帳號**。

---

## 先比較兩種需求描述

比較下面兩個例子的資訊量：

❌ **資訊不足**

```text
做一個幫學生提問的東西
```

✅ **列出功能與預期畫面**

```text
做一個探究提問卡網頁，學生輸入一個觀察到的現象就產生一張卡，
卡片上列出幾個可以追問的問題、能刪掉，資料要存得住，畫面乾淨、手機能用
```

Claude Code 可以執行清楚的要求，但不知道你沒有說明的條件。
中文介面、手機版面與配色偏好都需要寫進需求。

---

## 步驟 1：做出第一版

在 Claude Code 貼上這段話：

```text
在 inquiry/ 資料夾做一個「探究提問卡」小工具，單一個 index.html 檔案就好，不要用任何套件。
用途：學生輸入一個自己觀察到的現象，工具幫他把現象變成可以追問的問題。
功能：
1. 可以輸入一個觀察現象，按一下就新增一張卡
2. 每張卡自動列出三個提問方向：為什麼會這樣、如果改變一個條件會怎樣、可以怎麼測量
3. 下面列出所有卡片，每一張可以刪掉
4. 資料存在瀏覽器裡，關掉再打開還在
畫面請做得乾淨好看，中文介面，手機上也要能用。
做好之後幫我在瀏覽器打開來看。
```

它會開始寫檔案，中間會問你可不可以，按**同意**。

> **如果處理時間較長，可以查看它目前正在讀取或修改哪些檔案。**
> 等待時可以先決定下一步要增加的功能。

**你應該會看到**：瀏覽器打開一個可以輸入觀察現象的頁面。**實際輸入一個現象試試看**
（例如「同一株植物靠窗那側長得比較快」），然後**重新整理**——卡片應該還在。

確認這一版能動之後，先留一個可以回來的版本：

```text
先把目前能正常運作的第一版 commit，commit 訊息寫「完成探究提問卡第一版」，先不要改其他東西。
```

> 這個 commit 是一個**安全存檔點**。如果下一步修改後無法正常運作，可以回到這個版本。

---

## 步驟 2：改成你想要的樣子 ⭐

**這一步比第一版更重要。**

第一版可能有需要調整的地方，例如提問方向不符合你的學科、或缺少學生自己填寫的欄位。
請先選一項修改。

挑一個你想加的，貼上去。例如加上學生自己的提問欄：

```text
幫我在每張卡片上加一個「我想檢驗的問題」輸入欄，
學生可以自己寫一句話，寫完會跟著卡片一起存起來，重新整理後還在。
最上面顯示目前有幾張卡，其中幾張已經寫了要檢驗的問題。
```

或者換成你自己想要的：

```text
我想要（在這裡寫你想加的功能），請幫我加上去。
```

一些可以直接用的點子：

- 「提問方向改成適合我這一科，我教的是＿＿」
- 「加一個列印按鈕，可以把所有卡片印成一張學習單」
- 「卡片加上日期，並且可以依日期排序」
- 「加一個按鈕可以把所有卡片匯出成 CSV」

修改後不要只看 Claude 回覆「完成了」。回到瀏覽器，**實際測試新增的功能**，
再確認原本的新增、刪除、重新整理都還能用。

> **需要調整時，直接補充需求，不用重來。**
> 如果修改後無法正常運作，可以要求 Claude 還原剛才的改動。
> 請至少完成一次「修改、測試、確認」的流程。

---

## 步驟 3：存回 GitHub

```text
把這次新增的功能另做一個 commit，commit 訊息用中文清楚寫出改了哪一塊，然後 push 到 GitHub。
```

回到 GitHub 的 repo 頁面，點進你剛寫的 commit 訊息。你會看到這一小塊改動新增、刪除了什麼。
**不需要逐行閱讀程式碼；先確認改動都與新功能有關，而且沒有刪除其他功能。**

3. GitHub 上看得到**兩個分開的 commit**：第一版，以及你後來改的那一塊

三項都有 → Lab 1 完成，檔案也已存到 GitHub。

## 遇到問題？

| 你看到的 | 貼這句話給它 |
| --- | --- |
| 找不到檔案、不知道怎麼打開 | `幫我在瀏覽器打開這個頁面` |
| 重新整理資料就不見了 | `幫我開一個本機伺服器來打開這個頁面，這樣資料才存得住` |
| 畫面一片空白 | 按 <kbd>F12</kbd> 打開主控台，複製紅色錯誤訊息，貼上：<br>`畫面是空白的，主控台出現這個錯誤：（貼上）請修好它` |
| 修改後無法正常運作 | `請把剛剛的改動還原，回到上一個能正常運作的版本` |
| push 失敗 | 回頭確認 `lab-0-setup.md` 的檢查點有沒有過 |

遇到錯誤時，請完整複製錯誤訊息，貼回 Claude Code 並要求修正。

## 延伸練習

- 讓提問方向可以自己編輯，換成適合你這一科的句型
- 加上「這個問題可以怎麼檢驗」欄位，引導學生從提問走到方法
- 問它一個問題，看它怎麼回答：

```text
如果我想讓學生在自己的手機上填寫這些卡片，而且我這邊看得到，需要做什麼？
用我聽得懂的方式解釋，不要寫程式。
```
