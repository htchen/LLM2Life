# Lab 1：記帳小工具（33 分鐘）

## 這一段結束時，你會有

- 一個可以使用的記帳網頁，關閉後再開啟仍會保留資料
- 一次根據實際結果補充需求並修改的經驗
- 你的作品出現在 GitHub 上

> 記帳是這一段的練習題目。學習重點是**如何把需求說明清楚**。

---

## 先比較兩種需求描述

比較下面兩個例子的資訊量：

❌ **資訊不足**

```text
做一個記帳的東西
```

✅ **列出功能與預期畫面**

```text
做一個記帳網頁，可以輸入金額和項目、能刪掉、最上面顯示總花費，
資料要存得住，畫面乾淨、手機能用
```

Claude Code 可以執行清楚的要求，但不知道你沒有說明的條件。
中文介面、手機版面與配色偏好都需要寫進需求。

---

## 步驟 1：做出第一版

在 Claude Code 貼上這段話：

```text
在 expenses/ 資料夾做一個記帳小工具，單一個 index.html 檔案就好，不要用任何套件。
功能：
1. 可以輸入金額、項目名稱，按一下就新增一筆
2. 下面列出所有紀錄，每一筆可以刪掉
3. 最上面顯示這個月的總花費
4. 資料存在瀏覽器裡，關掉再打開還在
畫面請做得乾淨好看，中文介面，手機上也要能用。
做好之後幫我在瀏覽器打開來看。
```

它會開始寫檔案，中間會問你可不可以，按**同意**。

> **如果處理時間較長，可以查看它目前正在讀取或修改哪些檔案。**
> 等待時可以先決定下一步要增加的功能。

**你應該會看到**：瀏覽器打開一個記帳頁面。**實際輸入幾筆試試看**，
然後**重新整理**——資料應該還在。

確認這一版能動之後，先留一個可以回來的版本：

```text
先把目前能正常運作的第一版 commit，commit 訊息寫「完成記帳工具第一版」，先不要改其他東西。
```

> 這個 commit 是一個**安全存檔點**。如果下一步修改後無法正常運作，可以回到這個版本。

---

## 步驟 2：改成你想要的樣子 ⭐

**這一步比第一版更重要。**

第一版可能有需要調整的地方，例如顏色、字級或功能。請先選一項修改。

挑一個你想加的，貼上去。例如加分類：

```text
幫我加上「分類」功能：新增的時候可以選餐飲、交通、購物、其他，
列表上用不同顏色的標籤顯示，最上面再加一個各分類的小計。
```

或者換成你自己想要的：

```text
我想要（在這裡寫你想加的功能），請幫我加上去。
```

一些可以直接用的點子：

- 「加一個圖表，看這個月每個分類花了多少」
- 「顏色改成暖色系，我想要看起來溫暖一點」
- 「加一個按鈕可以把所有紀錄匯出成 CSV」
- 「金額加上千分位逗號，並顯示新台幣符號」

修改後不要只看 Claude 回覆「完成了」。回到瀏覽器，**實際測試新增的功能**，
再確認原本的新增、刪除、重新整理都還能用。

> **需要調整時，直接補充需求，不用重來。**
> 如果修改後無法正常運作，可以要求 Claude 還原剛才的改動。
> 請至少完成一次「修改、測試、確認」的流程。

---

## 步驟 3：存回 GitHub

```text
把這次新增的功能另做一個 commit，commit 訊息用中文清楚寫出改了哪一塊，然後 push 到 GitHub。
```

回到 GitHub 的 repo 頁面，點進你剛寫的 commit 訊息。你會看到這一小塊改動新增、刪除了什麼。
**不需要逐行閱讀程式碼；先確認改動都與新功能有關，而且沒有刪除其他功能。**

---

## ✅ 檢查點

1. 你的記帳頁面**能新增、能刪除、重新整理後資料還在**
2. 打開 `https://github.com/你的帳號/my-life-tools`，**看得到 `expenses/` 資料夾**
3. GitHub 上看得到**兩個分開的 commit**：第一版，以及你後來改的那一塊

三項都有 → Lab 1 完成，檔案也已存到 GitHub。

## 遇到問題？

| 你看到的 | 貼這句話給它 |
| --- | --- |
| 找不到檔案、不知道怎麼打開 | `幫我在瀏覽器打開這個頁面` |
| 重新整理資料就不見了 | `幫我開一個本機伺服器來打開這個頁面，這樣資料才存得住` |
| 畫面一片空白 | 按 <kbd>F12</kbd> 打開主控台，複製紅色錯誤訊息，貼上：<br>`畫面是空白的，主控台出現這個錯誤：（貼上）請修好它` |
| 修改後無法正常運作 | `請把剛剛的改動還原，回到上一個能正常運作的版本` |
| push 失敗 | 回頭確認 `lab-0-setup.md` 的檢查點有沒有過 |

遇到錯誤時，請完整複製錯誤訊息，貼回 Claude Code 並要求修正。
