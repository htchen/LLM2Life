# Lab 1：記帳小工具（33 分鐘）

## 這一段結束時，你會有

- 一個真的能用的記帳網頁，資料關掉再打開還在
- 一次「不滿意 → 再講一次 → 變好」的經驗 ← **這才是重點**
- 你的作品出現在 GitHub 上

> 記帳只是題目。這一段真正要學的是**怎麼把想法講成它聽得懂的話**。

---

## 先講一件事：怎麼跟它講話

這是今天唯一要記的觀念。看這兩個例子的差別：

❌ **太短，它只能用猜的**

```text
做一個記帳的東西
```

✅ **講清楚「有什麼功能」和「我要看到什麼」**

```text
做一個記帳網頁，可以輸入金額和項目、能刪掉、最上面顯示總花費，
資料要存得住，畫面乾淨、手機能用
```

**訣竅：想像你在交代一個很能幹但沒讀過你腦袋的人。**
他不知道你要中文介面、不知道你要放手機看、不知道你討厭什麼顏色——除非你講。

---

## 步驟 1：做出第一版

在 Claude Code 貼上這段話：

```text
在 expenses/ 資料夾做一個記帳小工具，單一個 index.html 檔案就好，不要用任何套件。
功能：
1. 可以輸入金額、項目名稱，按一下就新增一筆
2. 下面列出所有紀錄，每一筆可以刪掉
3. 最上面顯示這個月的總花費
4. 資料存在瀏覽器裡，關掉再打開還在
畫面請做得乾淨好看，中文介面，手機上也要能用。
做好之後幫我在瀏覽器打開來看。
```

它會開始寫檔案，中間會問你可不可以，按**同意**。

> **它跑很久是正常的**，它在讀檔案、寫檔案、檢查自己寫得對不對。
> 你可以趁這時候想：等一下我要加什麼功能？

**你應該會看到**：瀏覽器打開一個記帳頁面。**實際輸入幾筆試試看**，
然後**重新整理**——資料應該還在。

確認這一版能動之後，先留一個可以回來的版本：

```text
先把目前能正常運作的第一版 commit，commit 訊息寫「完成記帳工具第一版」，先不要改其他東西。
```

> 這個 commit 是你的**安全存檔點**。下一步改壞了，不用整份重來，可以回到這裡。

---

## 步驟 2：改成你想要的樣子 ⭐

**這一步比第一版更重要。**

第一版一定有你不滿意的地方——顏色、字太小、少了某個功能。**這很正常，而且很容易改。**

挑一個你想加的，貼上去。例如加分類：

```text
幫我加上「分類」功能：新增的時候可以選餐飲、交通、購物、其他，
列表上用不同顏色的標籤顯示，最上面再加一個各分類的小計。
```

或者換成你自己想要的：

```text
我想要（在這裡寫你想加的功能），請幫我加上去。
```

一些可以直接用的點子：

- 「加一個圖表，看這個月每個分類花了多少」
- 「顏色改成暖色系，我想要看起來溫暖一點」
- 「加一個按鈕可以把所有紀錄匯出成 CSV」
- 「金額加上千分位逗號，並顯示新台幣符號」

改完不要只看 Claude 說「完成了」。回到瀏覽器，**親手試一次剛加的功能**，
再確認原本的新增、刪除、重新整理都還能用。

> **不滿意就再講一次，不用重來。**
> 你不會把它弄壞——就算弄壞了，下一句「請還原剛剛的改動」就救回來了。
> 這件事請一定要親手試一次，這是今天最值得帶走的習慣。

---

## 步驟 3：存回 GitHub

```text
把這次新增的功能另做一個 commit，commit 訊息用中文清楚寫出改了哪一塊，然後 push 到 GitHub。
```

回到 GitHub 的 repo 頁面，點進你剛寫的 commit 訊息。你會看到這一小塊改動新增、刪除了什麼。
**不用看懂程式碼，只要確認改動都跟你剛要求的功能有關，沒有意外刪掉別的東西。**

---

## ✅ 檢查點

1. 你的記帳頁面**能新增、能刪除、重新整理後資料還在**
2. 打開 `https://github.com/你的帳號/my-life-tools`，**看得到 `expenses/` 資料夾**
3. GitHub 上看得到**兩個分開的 commit**：第一版，以及你後來改的那一塊

三項都有 → 你剛剛做出了一個軟體，而且它已經在網路上了。

## 卡住了？

| 你看到的 | 貼這句話給它 |
| --- | --- |
| 找不到檔案、不知道怎麼打開 | `幫我在瀏覽器打開這個頁面` |
| 重新整理資料就不見了 | `幫我開一個本機伺服器來打開這個頁面，這樣資料才存得住` |
| 畫面一片空白 | 按 <kbd>F12</kbd> 打開主控台，複製紅色錯誤訊息，貼上：<br>`畫面是空白的，主控台出現這個錯誤：（貼上）請修好它` |
| 改壞了，想回到剛剛 | `請把剛剛的改動還原，回到上一個能正常運作的版本` |
| push 失敗 | 回頭確認 `lab-0-setup.md` 的檢查點有沒有過 |

**最好用的一招：把錯誤訊息整段複製，貼回去說「請修好它」。**
你今天之後遇到的九成問題，都是這樣解決的。

- 加上預算：設定每月上限，超過的時候數字變紅色

```text
如果我想讓這個記帳工具在手機和電腦上看到同一份資料，需要做什麼？
用我聽得懂的方式解釋，不要寫程式。
```
