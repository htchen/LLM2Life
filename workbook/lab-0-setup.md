# Lab 0：把工具準備好（20 分鐘）

## 這一段結束時，你會有

- 一個叫 `my-life-tools` 的 GitHub repo，而且是 **Public**
- 這個 repo 下載到你自己的電腦裡
- **可以把改動上傳回 GitHub 的能力**（這是今天最關鍵的一步）

> 這一段有點瑣碎，但**所有麻煩的事情都在這裡一次解決**。
> 撐過這 20 分鐘，後面三個 Lab 就只剩下「講一句話、東西出現」。

---

## 步驟 1：確認 Claude Code 可以用

打開 **Claude 桌面版**，點最上方中間的 **Code** 分頁。

**你應該會看到**：一個可以輸入文字的畫面。

**如果跳出要你升級付費方案** → Claude Code 需要 Pro 以上的方案，免費帳號無法使用。
請**現在就舉手**，講師會安排你跟同學兩人一組，不要自己卡在這裡。

---

## 步驟 2：在 GitHub 上建立你的 repo

打開 https://github.com/new

填三個地方：

| 欄位 | 填什麼 |
| --- | --- |
| **Repository name** | `my-life-tools` |
| **Public / Private** | 選 **Public** ⚠️ |
| **Add a README file** | **打勾** ✅ |

然後按最下面的 **Create repository**。

> ⚠️ **一定要選 Public。** 今天最後一段要把你的作品變成一個公開網址，
> 免費帳號的 Private repo 沒辦法做到。現在選錯，等一下要花五分鐘回來改。

**你應該會看到**：一個網址是 `https://github.com/你的帳號/my-life-tools` 的頁面，
裡面有一個 `README.md` 檔案。

**把這個網址複製下來**，下一步要用。

---

## 步驟 3：把 repo 下載到你的電腦

回到 Claude 桌面版的 **Code** 分頁：

1. 環境選 **Local**
2. 按 **Select folder**，選一個你找得到的資料夾（例如「文件」或桌面）
3. 在下面的輸入框貼上這段話，**把網址換成你自己的**：

```text
請幫我把 https://github.com/你的帳號/my-life-tools 這個 repo 下載到這個資料夾。
```

Claude 會問你可不可以執行指令，按**同意**。

> **它會問你「可不可以」是正常的。** Claude Code 不會偷偷動你的電腦，
> 每次要改檔案或執行指令都會先問過你。

**你應該會看到**：Claude 回報下載完成，資料夾裡多了一個 `my-life-tools`。

---

## 步驟 4：打通「上傳」這條路 ⭐ 最重要的一步

下載下來很容易，**傳回去需要先證明你是你**。現在把它設定好，後面三個 Lab 就不會再卡。

貼上這段話：

```text
請幫我設定好 GitHub 的登入，讓我等一下可以把改動上傳回去。
如果需要我操作瀏覽器、複製代碼或輸入東西，請一步一步用中文告訴我，一次講一步。
設定好之後，請在 README.md 加一行「我的生活小工具」，然後 commit 並 push 上去。
```

Claude 會帶你走一次登入流程。通常是：它給你一組代碼 → 你在瀏覽器貼上 → 按同意。
**跟著它講的做就好**，看不懂就直接回它「我看到的畫面是……，接下來要按哪裡？」

---

## ✅ 檢查點

回到瀏覽器，打開你的 repo 頁面，**按 F5 重新整理**。

**你應該會看到**：`README.md` 裡多了「我的生活小工具」這一行。

看到了 → 今天最難的部分結束了，剩下的都是好玩的。
沒看到 → **舉手**。這一步沒過，後面每個 Lab 的最後一步都會卡住，一定要現在解決。

---

## 落後了？

**如果步驟 4 怎麼都過不去**，改走瀏覽器路線，完全不用安裝任何東西：

1. 打開 https://claude.ai/code
2. 用你的 Claude 帳號登入
3. 照畫面指示連結 GitHub 帳號
4. 在 repo 選單選 `my-life-tools`

這條路線的差別：**檔案在雲端，不在你的電腦裡**。你改完之後 Claude 會產生一個分支，
要按 **Create PR** 才會存回主要版本。

走這條路線的話，請**現在**先跳到 `lab-3-habits.md` 的「步驟 4：讓全世界都打得開」
把 GitHub Pages 開起來——這樣接下來每個 Lab 你都能用網址看到成果。

---

## 想再多做一點？

已經做完在等別人？試試看這個，順便熟悉一下怎麼跟它講話：

```text
幫我看看這個 repo 現在長什麼樣子，然後把 README.md 改成一個好看的介紹頁，
說明這裡會放我自己做的生活小工具。用中文寫。
```
