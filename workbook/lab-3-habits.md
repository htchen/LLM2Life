# 參考案例：習慣儀表板與 GitHub Pages

> 這份案例已移出課堂主線，供需要標準題目、發布步驟或課後延伸使用。

## 這一段結束時，你會有

- 一個習慣追蹤儀表板
- 一個把三個工具串起來的首頁
- 一個可以用手機開啟並分享的公開網址

> 這一段會把三個工具整理到同一個首頁，並使用 GitHub Pages 發布。

---

## 步驟 1：做習慣追蹤表（15 分鐘）

```text
在 habits/ 資料夾做一個習慣追蹤表，單一個 index.html：
1. 我可以自己新增想追蹤的習慣（例如喝水、運動、閱讀）
2. 顯示最近 30 天的格子，點一下代表那天有做到，變成綠色
3. 每個習慣顯示「連續達成幾天」
4. 資料存在瀏覽器裡，關掉再打開還在
中文介面，手機上要能用。做好幫我打開來看。
```

**你應該會看到**：一個格子狀的追蹤表。點幾格試試看，重新整理，顏色應該還在。

需要調整時就繼續修改，跟 Lab 1 一樣：

- 「格子太小了，放大一點」
- 「連續達成 7 天的時候給我一個慶祝動畫」
- 「加上這個月的達成率百分比」

---

## 步驟 2：做一個首頁（8 分鐘）

三個工具位於不同資料夾。接下來建立一個首頁，提供各工具的連結。

```text
在 repo 根目錄做一個 index.html 當首頁，用卡片的方式連到我做的工具：
- inquiry/ 探究提問卡
- habits/ 習慣追蹤表
- digest/ 每日摘要
風格要跟那兩個工具一致，中文介面，手機上要清楚易讀。
最上面放一個標題「我的生活小工具」。
```

---

## 步驟 3：全部存回 GitHub

```text
把全部改動 commit 並 push 到 GitHub。
```

完成 push 後再進行下一步。到 GitHub 頁面重新整理，確認看得到 `habits/`
和根目錄的 `index.html`。

---

## 步驟 4：發布成公開網站

這一步在 GitHub 網頁上做，不用 Claude Code。

1. 打開你的 repo：`https://github.com/你的帳號/my-life-tools`
2. 點上排的 **Settings**
3. 在**左邊**的選單往下捲，找到 **Pages**（在 “Code and automation” 那一區）
4. **Build and deployment** 底下：
   - **Source** 選 **Deploy from a branch**
   - **Branch** 選 **main**，右邊的資料夾選 **/ (root)**
5. 按 **Save**

**你應該會看到**：頁面上方出現一個網址，長這樣：

```
https://你的帳號.github.io/my-life-tools/
```

---

## 步驟 5：等待部署完成，然後用手機開啟

⚠️ **第一次部署要等 1–10 分鐘，而且剛開好時打開會是 404——這是正常的。**

趁等待的時候，把你的網址寫在紙上或傳給自己。

過幾分鐘後，**用你的手機**打開那個網址。

**你應該會看到**：你的首頁，可以點進提問卡和習慣追蹤，而且在手機上就能用。

---

## ✅ 檢查點

- [ ] `https://你的帳號.github.io/my-life-tools/` 打得開
- [ ] 首頁可以點到探究提問卡
- [ ] 首頁可以點到習慣追蹤表
- [ ] **用手機打開過了**

全部打勾 → 網站已完成發布。

---

## 打開是 404？

按這個順序查，多數是第 1 或第 2 項：

| # | 檢查 | 處理方式 |
| --- | --- | --- |
| 1 | **才剛按 Save？** | 再等 5 分鐘，第一次部署很慢 |
| 2 | **repo 是 Public 嗎？** | Settings → 最下面 Danger Zone → Change visibility → Public |
| 3 | **網址結尾有 `/` 嗎？** | `.../my-life-tools` ❌　`.../my-life-tools/` ✅ |
| 4 | **repo 名字打對了嗎？** | 大小寫要完全一樣 |
| 5 | **根目錄有 `index.html` 嗎？** | 沒有的話先開 `https://你的帳號.github.io/my-life-tools/habits/` |

如果樣式或圖片載入異常：

```text
這個頁面放到 GitHub Pages 上樣式跑掉了，請把所有路徑改成相對路徑，然後 push。
```

---

## 需要追上進度？

只做這兩件事就好，首頁可以不要：

```text
在 habits/ 資料夾做一個習慣追蹤表，單一 index.html：
可以新增習慣、顯示最近 30 天的格子、點一下變綠色、資料存在瀏覽器裡。
中文介面、手機能用。做好之後 commit 並 push 到 GitHub。
```

push 完直接跳到**步驟 4** 開 GitHub Pages，網址開 `.../my-life-tools/habits/`。

---

## 延伸練習

- 讓首頁顯示你這個月的花費和習慣達成率
- 「幫我把這三個工具的配色統一，做一個深色模式的切換」
- 把每日摘要也變成好看的網頁：

```text
做一個 digest/index.html，把 digest 資料夾裡所有的 .md 摘要列出來，
可以點進去看內容。中文介面，風格跟首頁一致。
```
