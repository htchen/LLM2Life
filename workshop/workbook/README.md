# 學員手冊（免費版）

這份手冊帶你從一項真實需求開始，完成發想、規劃、實作與驗證。**不需要程式背景、付費方案或軟體安裝。**

> 本版本需要自行把 AI 回覆建立成檔案，並在每次更新時取得完整程式碼。

## 今天會重複的流程

```text
提出問題 → 縮小目標 → 定義驗收條件 → 拆解步驟
→ 取得完整程式碼 → 存檔 → 測試 → 上傳版本
```

更新檔案時：**複製完整新版本 → 全選舊內容 → 貼上 → 存檔 → 重新整理瀏覽器**。

## 題目範圍

課堂專題限定為一個主要使用者、一個核心問題和一個可展示流程。
登入、資料庫、多人同步、付款、敏感個資與自動對外寄送都列入後續版本。

## 備用案例

- [`lab-2-digest.md`](lab-2-digest.md)：GitHub Actions 每日摘要
- [`lab-3-habits.md`](lab-3-habits.md)：習慣追蹤與 GitHub Pages

這兩份保留完整操作方式，但不再是全班必做主線。

## 三項操作重點

1. 每次都要求「請給我完整程式碼」。
2. 一次只增加一項功能，測試新功能也重新測試原有流程。
3. 未完成全部功能時，保留可操作版本並記錄下一步。
