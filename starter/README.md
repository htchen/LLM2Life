# 我的生活小工具

用 Claude Code 製作的生活小工具。

| 資料夾 | 做什麼 |
| --- | --- |
| `inquiry/` | 課堂共同練習 |
| `project/` | 個人專題的可操作版本 |

`digest/` 與 `habits/` 是課後可選的參考案例。

個人專題網址：`https://你的帳號.github.io/my-life-tools/project/`

---

## 後續修改方式

需要修改時，打開 Claude 桌面版的 **Code** 分頁，選擇這個資料夾，再描述要調整的內容。

幾句最常用的：

```text
把剛剛的改動還原，回到上一個能正常運作的版本
```

```text
（貼上錯誤訊息）請修好它
```

```text
把目前的改動 commit 並 push 到 GitHub
```

`CLAUDE.md` 裡寫了「要怎麼幫我做事」的規則，Claude Code 每次都會先讀它。
若需要調整合作方式，可修改該檔案。
