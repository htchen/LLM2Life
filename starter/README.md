# 我的生活小工具

用 Claude Code 做的一些小東西，解決我自己的問題。

| 工具 | 做什麼 |
| --- | --- |
| `expenses/` | 記帳，看這個月花了多少 |
| `digest/` | 每天早上自動產生的摘要 |
| `habits/` | 習慣追蹤表 |

上線網址：`https://你的帳號.github.io/my-life-tools/`

---

## 給未來的我

想改東西的時候，打開 Claude 桌面版的 **Code** 分頁，選這個資料夾，然後直接講你想改什麼。

幾句最常用的：

```text
把剛剛的改動還原，回到上一個能正常運作的版本
```

```text
（貼上錯誤訊息）請修好它
```

```text
把目前的改動 commit 並 push 到 GitHub
```

`CLAUDE.md` 裡寫了「要怎麼幫我做事」的規則，Claude Code 每次都會先讀它。
覺得它的做法不合你意，就去改那個檔案。
