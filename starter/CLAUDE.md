# CLAUDE.md

這個檔案是給 Claude Code 看的。它會在每次工作前讀這裡，照著下面的規則做事。

## 我是誰

我沒有程式背景。請以我可以直接操作並驗證結果的方式協助，
不要要求我先閱讀或修改程式碼。

## 跟我說話的方式

- 全部用**繁體中文**。
- 優先使用一般用語；必須使用專有名詞時，請用一句話解釋。
- 做完之後，用**一句話**告訴我你做了什麼、我現在該去看哪裡。
- 不要貼大段程式碼，改為說明「它會做什麼」及「如何驗證」。
- 需要我去點某個網頁或按某個按鈕時，**一次講一步**，講清楚按鈕在畫面的哪裡。

## 寫程式的規則

- **能用一個檔案解決，就不要用兩個。** 網頁請做成單一個 `index.html`，
  HTML、CSS、JavaScript 都寫在裡面。
- **不要用任何需要安裝的套件或框架**，不要 npm install，不要 build 步驟。
  我的電腦上可能沒有 Node.js。
- 網頁介面一律**繁體中文**，而且**手機上要能正常使用**。
- 需要存資料時用瀏覽器的 localStorage，不要用資料庫。
- 做完網頁之後，**主動幫我在瀏覽器打開來看**。

## 這個 repo 的樣子

```
my-life-tools/
├── index.html   # 首頁，連到下面三個工具
├── expenses/    # 記帳小工具
├── digest/      # 每天自動產生的摘要（GitHub Actions 寫進來的）
└── habits/      # 習慣追蹤表
```

這個 repo 會發布到 GitHub Pages，所以：

- 連結一律用**相對路徑**，不要用絕對路徑，以免發布後無法開啟。
- 根目錄的 `index.html` 是首頁；新增工具時，請同步加入連結。

## GitHub Actions

我會用 Actions 做「每天自動執行」的功能。寫 workflow 時：

- **一定要加 `workflow_dispatch`**，我需要能自己按按鈕執行，不然我等不到排程。
- **要寫回 repo 的話，一定要加 `permissions: contents: write`**，否則會失敗。
- 不要用需要 `npm install` 的套件，用 Node 內建的功能就好。
- 排程時間請用台灣時間換算成 UTC，並在旁邊用註解寫清楚。
